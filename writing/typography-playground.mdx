# Typography Playground

This is a demo article. It exists only to stress-test the article typography, so it has more headings, lists and odd combinations than a real article would. Use the typography lab at the bottom of the page to compare heading and code fonts, or add `?heading=literata` or `?mono=plex` to the URL.

Most articles start with a couple of paragraphs of introduction before the first heading shows up. This one does the same, so you can judge how a heading sits after a normal run of body text. Pay attention to how close the heading feels to the text that comes after it, compared to the text that comes before it.

## Why spacing matters more than size

A heading belongs to the content that follows it, not to the content before it. When the space above and below a heading is roughly the same, the heading floats in the middle and the reader has to work a little harder to understand where a section begins.

The fix is usually boring: less space after the heading, a bit more space before it, and sizes that don't shout. Most of the hierarchy can come from position and weight instead of raw size.

### Proximity

Things that are close together are perceived as related. That's the whole principle. A heading with 32px below it and 64px above it is technically following the rule, but on a phone screen those numbers eat a large part of the viewport.

### Rhythm

When spacing is a multiple of the body line height, the page starts to feel calmer, even if nobody could tell you why. The new `lh` unit makes this easy: `1lh` is exactly one line of the current element.

#### A smaller heading

Level four headings are where things usually go wrong. They're often only slightly larger than body text, but they inherit the same huge margins as a level two heading, which makes them look lost.

##### And an even smaller one

Level five is almost a label. It should be close to the paragraph it introduces, and it should not need the same breathing room as a section title.

## Code

Inline code like `margin-block: 1lh` should sit comfortably inside a line without pushing the lines apart. Blocks of code are a different beast:

```tsx
function Greeting({ name }: { name: string }) {
  const message = name ? `Hello, ${name}!` : 'Hello, stranger.'
  return <p className="greeting">{message}</p> // => != === <= >=
}
```

And some CSS for good measure:

```css
.article-prose {
  --baseline: 1lh;
}

.article-prose * + p {
  margin-top: var(--baseline);
}
```

## A deliberately long heading that wraps onto multiple lines on smaller screens

The line height of a heading matters most when it wraps. Too loose and the two lines look like two separate headings, too tight and the descenders collide with the ascenders of the line below.
